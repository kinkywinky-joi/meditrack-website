MEDITRACK WEBSITE — DEPLOY-READY PACKAGE

WHAT'S INCLUDED
- index.html: main responsive landing page
- styles.css: visual design, responsive layout, accessibility focus styles
- script.js: mobile navigation, scroll effects, current footer year
- images/logo.svg: custom MediTrack brand mark
- thank-you.html: confirmation page after a successful form submission

RUN LOCALLY
1. Extract this ZIP.
2. Open the extracted meditrack_ready folder in VS Code.
3. Install the "Live Server" extension by Ritwick Dey.
4. Right-click index.html > Open with Live Server.

PUBLISH + ENABLE THE CONTACT FORM (NETLIFY)
1. Create/sign in to a Netlify account.
2. Open https://app.netlify.com/drop
3. Drag the extracted meditrack_ready folder onto the page.
4. Once deployed, open the site's Forms area in Netlify.
5. Confirm form detection is enabled. If you enable it after the first deploy,
   trigger a new deploy so Netlify can scan the HTML form.
6. The form is named "meditrack-contact". Submissions will appear in the
   Netlify site's Forms area. Configure email notifications in Netlify.

IMPORTANT
- The contact form is configured for Netlify Forms. It will not store submissions
  when opened only as a local file or through Live Server; it becomes functional
  after deployment to Netlify with form detection enabled.
- The public website address and Netlify account must be created by the site owner.
- The statistics and team/project details in the page were retained from the
  supplied content; verify them before public launch.
- The phone screen is a visual product illustration, not a working medication app.
- This website is informational and is not a substitute for professional medical advice.
